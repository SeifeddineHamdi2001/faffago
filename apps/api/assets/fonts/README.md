# Label fonts (D-45)

Embedded in every label PDF, subset to the characters used.

| File                         | Font             | Covers                             |
| ---------------------------- | ---------------- | ---------------------------------- |
| `NotoSans-Regular.ttf`       | Noto Sans        | Latin, French, digits, punctuation |
| `NotoSans-Bold.ttf`          | Noto Sans Bold   |                                    |
| `NotoSansArabic-Regular.ttf` | Noto Sans Arabic | Arabic, with its letter shaping    |
| `NotoSansArabic-Bold.ttf`    | Noto Sans Arabic |                                    |

Source: the Noto project (github.com/notofonts), hinted TTF. Both families
are under the SIL Open Font License 1.1 (`OFL.txt`), which allows embedding
and redistribution.
