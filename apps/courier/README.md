# apps/courier

React Native (Expo, TypeScript) application for the Livreur and the Ramasseur,
from `docs/coursier.md`. Android only for version 1, installed by Faffa Go as a
signed APK.

Not scaffolded yet. It is built in phase 5 of `docs/PROGRESS.md`.

It needs an Expo development build rather than Expo Go, because of
`react-native-vision-camera` and `expo-sqlite` (tech-stack 4). Three
constraints shape every screen:

- **Offline first** — every scan is queued in SQLite with the UUID generated on
  the phone, and synced later. The queue must survive a forced logout, so a
  password regenerated by the admin never costs a courier his unsent scans.
- **Big targets** — at least 56 px, main actions at the bottom, readable in
  sunlight.
- **Same rules as the server** — the screens call `applyParcelAction` from
  `@faffago/shared` to decide offline whether a scan can be queued, and the API
  validates it again on arrival.
